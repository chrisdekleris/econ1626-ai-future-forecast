# How much will AI lift Australia's productivity by 2030?

An interactive web essay for ECON1626 Economics of Artificial Intelligence (RMIT University), Assessment 3.

Work in progress. The essay is built section by section in `forecast.html` and published with GitHub Pages.

Planned structure: landing and thesis, capabilities and economic channels, an Industry Week claim under test,
scenarios to 2030, policy recommendations, what could make the forecast wrong, methods and data, references.
